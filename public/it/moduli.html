Componente server - Python / Django

G3W-ADMIN

Il modulo server di G3W-SUITE. Scritto in Python su Django LTS, pubblica i progetti QGIS come servizi WebGIS mantenendo stili, form e relazioni. Gestisce utenti, gruppi, permessi di accesso e moduli funzionali attivabili per singolo progetto.

g3w-suite/g3w-admin
Client cartografico - JavaScript / Vue

G3W-CLIENT

Il viewer cartografico WebGIS. Scritto in JavaScript con Vue.js, si collega al server QGIS e offre navigazione della mappa, ricerche personalizzate, editing su web (anche in modalità offline), visualizzazione grafici DataPlotly, stampa e molto altro.

g3w-suite/g3w-client
Modulo opzionale - Python

G3W-ADMIN-PROCESSING

Integra le API di QGIS Processing direttamente in G3W-SUITE. Carica un file .model3 nel pannello di amministrazione e i tuoi algoritmi di geoprocessing diventano immediatamente disponibili nel client web, con supporto per elaborazione sincrona e asincrona (batch).

g3w-suite/g3w-admin-processing
Deployment - Docker

G3W-SUITE-DOCKER

Lo stack Docker ufficiale per avviare G3W-SUITE con un singolo comando. Include NGINX, PostgreSQL/PostGIS, QGIS Server e tutti i servizi necessari, già configurati. È il metodo di installazione raccomandato sia in sviluppo che in produzione.

g3w-suite/g3w-suite-docker
Modulo opzionale - CSS / JS

G3W-ADMIN-FRONTEND

Portale pubblico personalizzabile per G3W-SUITE. Sostituisce la schermata di accesso predefinita con una pagina di atterraggio con logo, titolo e lista dei gruppi cartografici pubblicati, configurabile per ogni installazione.

g3w-suite/g3w-admin-frontend
Modulo opzionale - Python - MIT

G3W-ADMIN-PDND

Integrazione di G3W-SUITE con la Piattaforma Digitale Nazionale Dati (PDND). Aggiunge l'autenticazione tramite voucher token richiesta dalle linee guida di interoperabilità italiane, abilitando l'esposizione di API WebGIS conformi agli standard AgID.

g3w-suite/g3w-admin-pdnd
Plugin integrato - JavaScript / Vue - MPL-2

G3W-CLIENT-PLUGIN-EDITING

Plugin JavaScript per la modifica collaborativa delle geometrie e degli attributi direttamente sul client cartografico. Permette agli utenti autorizzati di creare, modificare ed eliminare feature vettoriali con strumenti avanzati di snap, split e multi-relazione. Il codice è ora mantenuto all'interno di g3w-admin.

g3w-admin / editing
