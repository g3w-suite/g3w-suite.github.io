Features and Capabilities

Discover all the modules, technologies, and integrated tools in G3W-Suite, split between the web cartographic client and the administration panel.

Optimized Cartographic Client

Highly responsive interface for smartphones, tablets, and Desktop PCs. Includes integrated real-time GPS location features for field surveys and a customizable graphic layout with logos and texts of your organization.

Base Tools & Maps

Immediate integration with commercial and open-source base maps (OpenStreetMap, Google Maps, Bing Maps). Advanced searches with auto-zoom, layer transparency control, and structured legend view.

Advanced Tools & Charts

Integrated Query Builder for custom questions and searches. Native management of spatial relations, 1:N and N:M joins. Dynamic generation of interactive charts based on the QGIS **DataPlotly** plugin, historical time series, and multimedia attachments.

Online Relational Editing

Modify geometric shapes and attributes directly from the web, inheriting widgets and form designs configured in QGIS. Feature locking to prevent multi-user edit conflicts and offline editing for connectionless areas.

Active Client
Premium Interface: Supports high-resolution printing by perfectly inheriting the layout composers and print templates defined in QGIS Desktop, including geographic Atlases.

Fast Project Publishing

Create and organize thematic geographic groups on the web. Immediate publishing by uploading the `.qgz` project file. Full graphic correspondence of legends, styles, vector, and raster layers.

Real-time Data Synchronization

Direct integration with corporate relational and spatial databases: PostgreSQL/PostGIS, Oracle Spatial, MSSQL Server. Support for lightweight local formats like SQLite/SpatiaLite, GeoPackage, Shapefile, and raster formats.

Surgical User Profiling

Independent user and group management with diversified roles. Configure permissions for editing individual layers and enable geographic filters and alphanumeric constraints (SQL / QGIS Expression) specific to each user.

Modules Integrated for PA

Enable modules dedicated to Public Administration: cadastral integration, CDU (Certificate of Urban Destination) with dedicated print layouts, address registry and house number management modules complying with RNDT and INSPIRE standards.

Administration
Admin Interface: Allows to manage cache regeneration, file system synchronization, and user access monitoring with extreme simplicity.
Robust Architecture

Infrastructure and Open Standards

G3W-Suite is designed to guarantee stability, high performance, and full compatibility with international geographic standards.

QGIS Server

Leverages 100% of QGIS Server APIs and engine to perfectly render your graphic styles and maps.

OGC Standards

Full compliance with international WMS, WFS, WCS standards and CSW specifications for geographic metadata.

Spatial Databases

Deep integration with popular relational and geographic databases with support for complex spatial queries.

API & Extensibility

Ability to extend core features by writing custom modules and integrating with third-party APIs.
