Why G3W-Suite?

Main Features

All the tools you need for geographical sharing and editing in a single scalable infrastructure.

Simple and Fast

Configure your project on QGIS Desktop, upload data to GeoDB or file system, and publish to WebGIS in a few clicks.

  • Zero programming
  • Seamless QGIS integration

Customizable

Customize the portal interface, logos, and texts of the access page and cartographic client. Manage admin environments and roles.

  • Custom access portal
  • Modular active features

Web Editing

Advanced geographical and alphanumeric editing, with native QGIS relationships support. Feature locking to prevent multi-user overwrites.

  • 1:1 and 1:N relationships
  • Spatial constraints & filters

User Profiling

Define users, groups, and roles to surgically differentiate viewing, editing, and administration permissions.

  • LDAP/Active Directory integration
  • Geographic access controls

Advanced Functions

Prints based on layout composer (with Atlas support), charts visualization with DataPlotly, time series, and custom search filters.

  • Support for print Atlases
  • DataPlotly integration

Desktop & Mobile

The cartographic client interface is fully responsive and optimized for viewing and editing on smartphones and tablets.

  • Mobile friendly interface
  • Integrated GPS support
Simple & Efficient

Publish in 4 Simple Steps

Transform your desktop cartographic projects into collaborative webGIS platforms.

1. Create your QGIS project

Design your map in QGIS Desktop setting up advanced styles, labels, print layouts, joins, relationships, and editing forms.

1

2. Sincronize spatial data

Load your databases (PostGIS/PostgreSQL, Oracle Spatial) or local files (SpatiaLite, GeoPackage, Shapefile, Raster) for rapid access.

2

3. Publish your project

Access the G3W-Suite web admin panel and upload your `.qgz` or `.qgs` project file. The WebGIS client is generated instantly.

3

4. Manage access and features

Create user groups, define read/write permissions, activate add-on modules, and customize geographical search filters.

4
