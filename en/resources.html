Installation

Quick Start Installation Guide

Install G3W-Suite locally using Docker and publish your first map in 4 steps.

1. Prepare data and map

Use QGIS Desktop to configure your map: define legends, labels, and styles. Make sure to place your geographic data inside a PostGIS database or a local GeoPackage archive.

1

2. Launch G3W-Suite with Docker

The fastest way to install G3W-Suite is using Docker. Make sure you have Docker and Docker Compose installed, then run the following in your terminal:

# Clone the Docker infrastructure
git clone https://github.com/g3w-suite/g3w-suite-docker.git
cd g3w-suite-docker

# Launch containers in the background
docker-compose up -d
2

3. Install the Plugin in QGIS

Open QGIS Desktop, select Plugins > Manage and Install Plugins and search for "G3W-Suite Publisher". Install the plugin to enable guided publishing.

3

4. Connect and Publish

Click the plugin icon in QGIS. Add a new server by entering your instance URL (e.g. http://localhost:8080) and your administration credentials. Select the current QGIS project and click Publish. Your WebGIS is ready!

4
