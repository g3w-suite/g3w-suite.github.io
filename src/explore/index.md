# Explore G3W-SUITE

Publish QGIS projects as interactive WebGIS services, keeping the maps, forms and workflows your team already knows.

[Try the demo](#demo-3-11 "primary-button") [Quick Start](/en/docs/quick-start/ "outline-button")

![WebGIS map client](/img/site-webgis-client-preview.jpg)

## <span id="features"></span>From QGIS to the web

### Publish and organize

Publish projects with their styles, forms, relations and print layouts. Organize maps into groups and manage users and permissions.

### Collaborate and edit

Edit geometries, attributes and related records in the browser, with configurable forms and multi-user feature locks.

### Explore and analyze

Search and query maps, view DataPlotly charts, print atlases and run QGIS Processing models from the web.

### Connect your data

Use spatial databases, files and raster layers alongside WMS and WFS services. Responsive maps support work on desktop and mobile devices.

## <span id="components"></span>Components and extensions

G3W-SUITE combines an administration server and a map client with optional integrations. Explore each component for its documentation and source code.

- [**G3W-ADMIN**](/en/explore/g3w-admin/) — publish projects and manage users, permissions and modules.
- [**G3W-CLIENT**](/en/explore/g3w-client/) — explore and work with maps in the browser.
- [**Collaborative editing**](/en/explore/g3w-client-plugin-editing/) — edit geographic features and related records together.
- [**G3W-ADMIN-PROCESSING**](/en/explore/g3w-admin-processing/) — run QGIS Processing models on the web.
- [**G3W-ADMIN-FRONTEND**](/en/explore/g3w-admin-frontend/) — create a branded public portal for map groups.
- [**G3W-ADMIN-PDND**](/en/explore/g3w-admin-pdnd/) — integrate PDND authentication.
- [**G3W-SUITE-DOCKER**](/en/explore/g3w-suite-docker/) — deploy the platform with the official Docker stack.

The core components use the MPL-2 licence; optional integrations may use their own licence. All source repositories are available on [GitHub](https://github.com/g3w-suite).
