# Comune di Bari

![Comune di Bari](/img/site-bari-city-logo.avif)

Supported releases:

[3.3](/en/news/v3.3/) · [3.4](/en/news/v3.4/)

The Municipality of Bari publishes its municipal WebGIS through G3W-SUITE. The online portal makes geographic information about the city available to residents and other map users.

The Municipality supported G3W-SUITE versions 3.3 and 3.4.

Version 3.3 introduced layer- and user-specific editing permissions and support for QGIS expressions in online editing. It also added QGIS map themes, searches across related data and links that open individual features directly on the map.

Administrators can configure editing rights for a specific user and layer instead of applying the same operations across a whole project. QGIS expressions carry project rules into the browser-based workflow, while map themes provide alternate views of the published layers.

Version 3.4 added cascading and conditional forms, raster and vector time-series visualisation, and tools for measuring geometry while editing. Users could also start editing directly from query or search results.

Conditional forms can show relevant fields in response to entered values, and cascading forms can connect related choices. Time-series visualisation brings changing raster or vector data into the map client. Query results can lead directly into editing, with geometry measurements available in the same workflow.

The releases cover both sides of a published WebGIS: map users can find and inspect features, while administrators control editing access and configure forms for the underlying QGIS project.

Bari is the capital of Apulia and a coastal regional centre on the Adriatic. Its neighbourhoods and urban territory are the geographic context for the municipal WebGIS, which makes the municipality's geographic information available through an online map.
