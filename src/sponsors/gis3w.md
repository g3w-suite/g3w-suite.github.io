# Gis3W

Gis3W is the main sponsor of G3W-SUITE and provides consulting, technical support and custom development for organisations using the platform.

G3W-SUITE is an open-source WebGIS platform for publishing QGIS projects on the web. It brings the maps, styles, forms, relations and print layouts prepared in QGIS into an interactive browser-based environment.

Gis3W is also a Mergin Maps partner for field data collection workflows.

The platform combines G3W-ADMIN, which manages projects and access, with G3W-CLIENT, the interface for working with maps. Optional components add capabilities such as collaborative editing, QGIS Processing models and a public portal. The source repositories are available on GitHub, and the core components use the MPL-2 licence.

Users can search and query geographic data, explore charts, print maps and work with features and related records. The platform supports different data sources, including spatial databases, files and raster layers, as well as web services such as WMS and WFS. Its map client is designed for both desktop and mobile use.

Gis3W provides professional services around the platform, including technical support, consulting and custom development. Organisations can install G3W-SUITE themselves or discuss managed hosting and support with the team. Documentation and a public demo are available for those who want to explore the platform independently.

The team also works with Mergin Maps, a tool for field data collection based on QGIS. This partnership connects web mapping with workflows that involve collecting and updating geographic information outside the office.

Version 3.0 introduced QGIS API integration.

The supported releases added DataPlotly charts and Atlas printing in 3.1, saved themes and PDF exports in 3.8, a redesigned map client and editing-configuration options in 3.9, and QGIS 3.40 LTR compatibility, annotations and Elasticsearch search in 3.10.
