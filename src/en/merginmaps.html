MerginMaps partnership

Gis3W provides support, at every level, for the Mergin Maps solution dedicated to field data collection based on QGIS.

With the OS solution Mergin Maps you can:

  • set up field data acquisition apps by defining features and functionality on QGIS projects
  • define data entry forms using QGIS modules, widgets and editing tools
  • easily synchronize your data to a centralized server, with conflict management
  • easily integrate your geospatial infrastructure
  • connect an external high-precision GPS for precision surveys

Integration with G3W-SUITE

Future developments will bring integration of QGIS projects published on G3W-SUITE with those available on Mergin Maps:

  • a single administration point to publish on the web and on the app
  • user sharing
  • ease of use and management
  • API integration

Gis3W, official partner of Mergin Maps, provides:

  • Training: QGIS project preparation, creation and design of data entry forms, background maps, field data collection, synchronization and everything needed for the best results
  • Consulting and support: project structuring, connection and synchronization with centralized database, customized solutions
  • Development: thanks to collaboration with MerginMaps developers, we offer customization services, custom releases and addition of new features
