Have you completed the installation of the suite on your server, or do you want to try publishing a project on the on-line demo?

Find out how easy it is to do it in four simple steps!

1

Create your QGIS project

Create your QGIS cartographic project defining all the aspects of interest: map content, symbology and labelling, legend structure, attribute query form, print layouts (free and atlas) and much more.

Remember to organize your projects and geographic data on your PC as illustrated and described in the manual.

2

Upload your geographic data to the server

If your project is based on local files (Shp, GeoPackage, SpatiaLite, raster) it is necessary that such data is present on the server at the time of publication.

The FileManager module will allow you to upload such data reconstructing the same organization set up locally.

If your geographic data is on a PostGis or Oracle Spatial GeoDB, you simply need to allow access from the suite.

3

Access G3W-SUITE and create the container for publishing

In order to publish a QGIS project you need to create a Cartographic Group: these Groups are containers that allow you to thematically and functionally organize your WebGis services.

You can publish multiple WebGis services within each Cartographic Group, but remember that they must have the same projection system associated with the Group when created.

4

Publish your QGIS project as a WebGis service

Publish your QGIS project by uploading the file (.qgs or .qgz) within the created Cartographic Group. No plugin needed!

All the settings and functions activated on the project will be automatically inherited by the WebGis service.

If you want to customize and activate additional functions on the online map, consult the manual and the online tutorial.
