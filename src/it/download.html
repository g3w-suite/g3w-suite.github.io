In hosting o on-premise

Tutto quello che serve per i tuoi WebGIS QGIS

Dalla pubblicazione del progetto all'editing collaborativo sul web, G3W-SUITE eredita automaticamente stili, form e relazioni dal tuo file QGIS.

  • Semplice e veloce

    • Crea il tuo progetto QGIS
    • Usa dati su GeoDB o file system
    • Pubblica su WebGis

  • Profilazione utenti

    Definisci utenti, gruppi e ruoli per differenziare gestione, accesso, editing on line e uso dei moduli funzionali

  • Personalizzabile

    • Personalizza contenuti del portale di accesso e del client cartografico
    • Crea ambienti gestionali e definisci i relativi amministratori
    • Attiva i moduli funzionali di interesse

  • Ricco di funzionalità

    • Integrazione con le API di QGIS
    • Ricerche personalizzabili
    • Layout di stampa standard o basati su atlanti geografici
    • Visualizzazione grafici basati sul plugin DataPlotly
    • Time series e grafici temporali
    • Servizio CSW per la metadatazione (RNDT e INSPIRE)

  • Editing on web

    • Editing geometrico e degli attributi anche su relazioni 1:1 e 1:N
    • Editing basato sulle API di QGIS
    • Form ed widget di editing ereditati da progetto QGIS
    • Feature lock per l'editing multi utente
    • Vincoli geografici ed alfanumerici personalizzabili per i singoli utenti

  • Desktop e mobile

    • Client responsive per la consultazione desktop e tablet
    • Editing su web anche in modalità off line

Alternativa al self-hosting

Non vuoi gestire l'infrastruttura?

G3W-Suite è open source e puoi installarla in autonomia seguendo il Quick Start. Se preferisci non occuparti di server, aggiornamenti e backup, GIS3W offre un servizio di hosting gestito: il tuo WebGIS QGIS operativo in pochi giorni, con SSL, backup giornalieri e supporto tecnico inclusi.

Richiedi informazioni sull'hosting Quick Start (self-hosted)
  • Server dedicato Ubuntu Server LTS
  • SSL/HTTPS automatico con Let's Encrypt
  • Backup giornalieri (retention 30 giorni)
  • Aggiornamenti di G3W-Suite inclusi
  • PostgreSQL/PostGIS dedicato e ottimizzato
  • Supporto tecnico GIS3W

Hai completato l'installazione di G3W-SUITE o vuoi provare a pubblicare un progetto sulla demo online?

Scopri come è semplice realizzarlo in quattro semplici passi!

1

Crea il tuo progetto QGIS

Crea il tuo progetto QGIS definendo tutti gli aspetti di interesse: contenuto della mappa, simbologia ed etichettatura, struttura legenda, form di consultazione degli attributi, layout di stampa (libero ed atlas) e molto altro ancora.

Ricorda di organizzare sul tuo pc, progetti e dati geografici come illustrato e descritto nel manuale.

2

Carica i tuoi dati geografici sul server

Se il tuo progetto si basa su file locali (Shp, GeoPackage, SpatiaLite, raster) è necessario che tali dati siano presenti sul server al momento della pubblicazione.

Il modulo FileManager ti permettera di caricare tali dati ricostruendo la stessa organizzazione predisposta in locale.

Se i tuoi dati geografici si trovano su un GeoDB PostGis o Oracle Spatial, devi semplicemente consentire l'accesso dalla suite.

3

Accedi a G3W-SUITE e crea il contenitore per la pubblicazione

Al fine di pubblicare un progetto QGIS occorre creare un Gruppo Cartografico: tali Gruppi sono contenitori che ti permettono di organizzare tematicamente e funzionalmente i tuoi servizi WebGIS.

Puoi pubblicare più servizi WebGIS all'interno di ogni Gruppo Cartografico, ricorda però che questi dovranno avere lo stesso sistema di proiezione associato al Gruppo in fase di creazione.

4

Pubblica il tuo progetto QGIS come servizio WebGis

Pubblica il tuo progetto QGIS caricando il file (.qgs o .qgz) all interno del Gruppo Cartografico creato. Nessun plugin necessario!

Tutte le impostazioni e funzioni attivate sul progetto saranno ereditate automaticamente dal servizio WebGis.

Se vuoi personalizzare ed attivare ulteriori funzioni sulla mappa on line consulta il manuale ed il tutorial on line.
