## Beyond G3W-SUITE

My Leaflet projects solve map problems directly: [leaflet-elevation](https://github.com/Raruto/leaflet-elevation) draws elevation profiles with SVG and Canvas, [leaflet-rotate](https://github.com/Raruto/leaflet-rotate) rotates maps, and [leaflet-kmz](https://github.com/Raruto/leaflet-kmz) loads KMZ data. I also publish technical notes on [Raruto](https://raruto.github.io/).

The leaflet-elevation examples explore routes from GPX, GeoJSON, KML and TCX files, with profiles for elevation and other measurements such as slope or speed. The project also demonstrates ways to customize charts, switch between tracks and connect the profile to the map.

Other plugins address everyday map interaction. [leaflet-transparency](https://github.com/Raruto/leaflet-transparency) adds an opacity control, while [leaflet-gesture-handling](https://github.com/Raruto/leaflet-gesture-handling) helps manage scrolling and touch gestures. Each project is published with its source code and examples for developers.

## In G3W-SUITE

I work on the suite's extension points and release flow: plugin-author guidance and build automation in G3W-CLIENT, plus the move of G3W-ADMIN's editing tool to a static plugin and Sentry monitoring integration. [Plugin development guide](https://github.com/g3w-suite/g3w-client/pull/977) · [Editing plugin change](https://github.com/g3w-suite/g3w-admin/pull/1184) · [Sentry integration](https://github.com/g3w-suite/g3w-admin/commit/133f18b0).

The plugin guide gives developers a starting point for extending the client, while the release workflow helps automate a recurring part of publishing new versions. My client contributions also include updates to build dependencies and interface behavior, such as hiding an empty themes selector for anonymous users.

These contributions connect the public map interface with the tools used to build, release and extend it. Explore the linked repositories for code, examples and the conversations behind individual changes.
