# Walter Lorenzetti

![Walter Lorenzetti](https://github.com/wlorenzetti.png?size=400)

**I work on G3W-ADMIN, developing the server and administration interface used to run WebGIS projects.**

## Beyond G3W-SUITE

My public repositories include small [Linux scripts](https://github.com/wlorenzetti/linux-scripts) and [mdojo](https://github.com/wlorenzetti/mdojo), a Django app for managing a Japanese martial arts dojo. It is a different field, but still software for keeping everyday operations organized.

Other repositories include a [Python wrapper for the ownCloud administration API](https://github.com/wlorenzetti/owncloudAdminClient) and [pg_change_owner](https://github.com/wlorenzetti/pg_change_owner), a utility for changing ownership of PostgreSQL tables, views and sequences.

These projects cover tasks on both sides of a service: administering the software itself and helping people manage the information it holds. They also show the role Python and database tools play in my public work.

## In G3W-SUITE

My recent G3W-ADMIN work added an Embedded column to the layers list and improved how layer titles are shown. Other updates handle authentication failures and submit logout through a form. Each change makes the admin workbench a little clearer and more dependable. [Embedded layer column](https://github.com/g3w-suite/g3w-admin/commit/bb9e5b208e37361415d6555de370686c78240bd1) · [Authentication responses](https://github.com/g3w-suite/g3w-admin/commit/739dcc3b) · [Logout form](https://github.com/g3w-suite/g3w-admin/commit/8ea12ea0).

My contributions also include the Elasticsearch configuration module and work on the platform's Python, Django and Qt dependencies. Other changes touch editing widgets, forms and translations, all parts of the administration environment used alongside published maps.

From layer management to sign-in and configuration, the server provides the workspace in which projects and permissions are organized. My work addresses both the code behind that workspace and the interface administrators use.
