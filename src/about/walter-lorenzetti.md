# Walter Lorenzetti

![Walter Lorenzetti](https://github.com/wlorenzetti.png?size=400)

**Walter Lorenzetti works in the engine room of G3W-ADMIN, shaping the server behavior and admin interface used to run WebGIS projects.**

## Beyond G3W-SUITE

His public repositories have a practical tinkering streak: small [Linux scripts](https://github.com/wlorenzetti/linux-scripts) and [mdojo](https://github.com/wlorenzetti/mdojo), a Django app for managing a Japanese martial arts dojo. It is a different field, but still software for keeping everyday operations organized.

## In G3W-SUITE

Recent G3W-ADMIN work added an Embedded column to the layers list and improved how layer titles are shown. Other updates handle authentication failures and submit logout through a form. Each change makes the admin workbench a little clearer and more dependable. [Embedded layer column](https://github.com/g3w-suite/g3w-admin/commit/bb9e5b208e37361415d6555de370686c78240bd1) · [Authentication responses](https://github.com/g3w-suite/g3w-admin/commit/739dcc3b) · [Logout form](https://github.com/g3w-suite/g3w-admin/commit/8ea12ea0).
