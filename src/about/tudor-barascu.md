# Tudor Barascu

![Tudor Barascu](https://github.com/tudorbarascu.png?size=400)

**I work with QGIS, from beginner-friendly plugins and server tutorials to Romanian GIS data and G3W-SUITE translations.**

[GitHub profile](https://github.com/tudorbarascu) · [QGIS Minimal Plugins](https://github.com/tudorbarascu/qgis_minimal_plugins) · [QTIBIA](https://qtibia.com)

## In G3W-SUITE

In G3W-ADMIN, I have contributed Romanian translations, including the file manager, updated the QGIS reference from 3.28 to 3.34, and added feature IDs to the locked-features list. These changes make the interface and its documentation clearer for administrators. [Romanian file manager](https://github.com/g3w-suite/g3w-admin/commit/5c60bb9e) · [QGIS reference update](https://github.com/g3w-suite/g3w-admin/commit/06d8d99c) · [Locked-feature IDs](https://github.com/g3w-suite/g3w-admin/commit/c3af3e1b).

My Romanian translation work also extends to G3W-CLIENT, including print-related text. The locked-features change makes the relevant feature identifier visible in the administration list, helping administrators distinguish records when editing is in progress.

I am also connected with [QTIBIA](/en/sponsors/qtibia/), whose work includes QGIS training and geographic information services. The resources linked here offer starting points for learning, translation and working with Romanian spatial data.

## Beyond G3W-SUITE

My public repositories include [QGIS Minimal Plugins](https://github.com/tudorbarascu/qgis_minimal_plugins), described as a starting point for newcomers, [QGIS Server tutorial data](https://github.com/tudorbarascu/qgis-server-tutorial-data), and a [Stereo70 to ETRS89 reference](https://github.com/tudorbarascu/stereo70-etrs89). Together they connect GIS software, learning resources and Romanian geodata.

QGIS Minimal Plugins takes an incremental approach: small examples introduce plugin development one step at a time. The repository is intended for people starting to work with QGIS plugins and builds on an existing minimal-plugin example.

The QGIS Server tutorial data provides material for learning about map services, while the Stereo70 reference concerns coordinate transformation between a Romanian reference system and ETRS89. Both sit close to the everyday work of preparing and sharing geographic information.
