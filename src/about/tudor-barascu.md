# Tudor Barascu

![Tudor Barascu](https://github.com/tudorbarascu.png?size=400)

**Tudor Barascu brings a practical QGIS perspective, from beginner-friendly plugins and server tutorials to Romanian GIS data and G3W-SUITE's language support.**

## Beyond G3W-SUITE

His public repositories include [QGIS Minimal Plugins](https://github.com/tudorbarascu/qgis_minimal_plugins), described as a starting point for newcomers, [QGIS Server tutorial data](https://github.com/tudorbarascu/qgis-server-tutorial-data), and a [Stereo70 to ETRS89 reference](https://github.com/tudorbarascu/stereo70-etrs89). Together they connect GIS software, learning resources and Romanian geodata.

## In G3W-SUITE

In G3W-ADMIN, Tudor has contributed Romanian translations, including the file manager, updated the QGIS reference from 3.28 to 3.34, and added feature IDs to the locked-features list. These changes make the interface and its documentation clearer for administrators. [Romanian file manager](https://github.com/g3w-suite/g3w-admin/commit/5c60bb9e) · [QGIS reference update](https://github.com/g3w-suite/g3w-admin/commit/06d8d99c) · [Locked-feature IDs](https://github.com/g3w-suite/g3w-admin/commit/c3af3e1b).
