# About G3W-SUITE

G3W-SUITE is an open-source WebGIS project that publishes QGIS projects on the web and supports the teams that manage and use geographic information.

![G3W-SUITE WebGIS client](/img/site-webgis-client-preview.jpg)

## Built around QGIS

The project connects QGIS Desktop and QGIS Server with tools for publishing maps, managing users and permissions, editing data online, and sharing geographic information.

Its modular architecture is developed in the open. Explore the [components](/en/explore/#components), read the [documentation](/docs/), or join the [community](/en/community/).
