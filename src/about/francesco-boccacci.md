# Francesco Boccacci

![Francesco Boccacci](https://github.com/volterra79.png?size=400)

**Francesco Boccacci moves between server code and the map interface, bringing a long view of GIS and a hands-on feel for web mapping.**

## Beyond G3W-SUITE

His public code reaches beyond G3W-SUITE: an [AniMove plugin for SEXTANTE/QGIS](https://github.com/volterra79/sextante_animove), a [Leaflet course](https://github.com/volterra79/corso-leaflet), and a [Vue 3 + OpenLayers example](https://github.com/volterra79/ol-vue-vite). The thread running through them is practical: make spatial tools useful in real work, whether inside QGIS or the browser.

## Across the platform

In G3W-CLIENT, his recent work touches both visible usability and maintainability: collapsed sidebars keep their icons, form components are being refactored, and context menus no longer require the editing plugin. These changes make the interface easier to navigate and the client easier to extend. [Sidebar icons](https://github.com/g3w-suite/g3w-client/commit/d3029acb) · [Form refactor](https://github.com/g3w-suite/g3w-client/commit/7462bcf3) · [Context menu](https://github.com/g3w-suite/g3w-client/commit/6595aa57).
