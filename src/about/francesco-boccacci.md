## Beyond G3W-SUITE

My public code reaches beyond G3W-SUITE: an [AniMove plugin for SEXTANTE/QGIS](https://github.com/volterra79/sextante_animove), a [Leaflet course](https://github.com/volterra79/corso-leaflet), and a [Vue 3 + OpenLayers example](https://github.com/volterra79/ol-vue-vite). These projects explore spatial tools in QGIS and the browser.

The AniMove repository connects QGIS and the SEXTANTE processing framework with tools for animal movement. My Leaflet course and OpenLayers example, meanwhile, explore maps in the browser using different JavaScript libraries.

My public projects also include [webgisclient](https://github.com/volterra79/webgisclient), described as a web GIS client framework, and [postgisbbox](https://github.com/volterra79/postgisbbox). They connect spatial data, server applications and interactive maps.

## Across the platform

In G3W-CLIENT, my recent work touches both visible usability and maintainability: collapsed sidebars keep their icons, form components are being refactored, and context menus no longer require the editing plugin. These changes make the interface easier to navigate and the client easier to extend. [Sidebar icons](https://github.com/g3w-suite/g3w-client/commit/d3029acb) · [Form refactor](https://github.com/g3w-suite/g3w-client/commit/7462bcf3) · [Context menu](https://github.com/g3w-suite/g3w-client/commit/6595aa57).

My G3W-ADMIN contributions also include work on the editing plugin: showing all vertices of a multi-geometry feature and unlocking a layer after an edit is committed inside an iframe. These changes address the details of working with spatial features in a shared web interface.

Forms, layer controls and editing tools are points where the underlying GIS meets the person using the map. My work on both client and administration code helps bring those pieces together.
