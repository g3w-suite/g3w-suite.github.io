# Andrea Antonello

![Andrea Antonello](https://github.com/moovida.png?size=400)

**Andrea Antonello connects geospatial software with the tools people use to build it, from GIS libraries in Dart to G3W-SUITE localization.**

## Beyond G3W-SUITE

Through [G-ANT Scientific Solutions](https://g-ant.eu) and his public repositories, he works on the geospatial ecosystem around mobile and open data: [dart_jts](https://github.com/moovida/dart_jts) ports part of the Java Topology Suite to Dart, while [flutter_geopackage](https://github.com/moovida/flutter_geopackage) and [dart_shp](https://github.com/moovida/dart_shp) bring common GIS formats to Dart and Flutter apps. He also maintains small utilities for a reMarkable tablet.

## In G3W-SUITE

In G3W-ADMIN, Andrea has worked on localization tooling: export/import helpers built around `manage.py`, followed by updates to module labels and German translations. He also fixed an OpenRouteService label in the sitetree translations. These changes make the admin interface easier to translate and keep in sync. [Translation tooling](https://github.com/g3w-suite/g3w-admin/commit/ca394118) · [Sitetree update](https://github.com/g3w-suite/g3w-admin/commit/7dc474e2).
