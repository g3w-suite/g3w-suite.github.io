# Leonardo Lami (@leonardolami)

![Leonardo Lami](https://github.com/leonardolami.png?size=400)

**Leonardo Lami (@leonardolami) has helped keep the G3W-SUITE manual aligned with its releases, turning upgrades and changes into steps administrators can follow.**

His public work is focused on Gis3W and G3W-SUITE rather than a separate tool portfolio. The visible thread is release-by-release documentation maintenance: quiet work that matters most when an administrator needs a reliable answer.

## In code and documentation

Public commits show manual updates for versions 3.1, 3.2, 3.3 and 3.4, including upgrade guidance and corrections to the introduction and images. Each release is easier to adopt when its documentation catches up. [Manual 3.1 update](https://github.com/g3w-suite/g3w-admin/commit/22c4df2f) · [Version 3.4 documentation and image](https://github.com/g3w-suite/g3w-admin/commit/16d65b21).
