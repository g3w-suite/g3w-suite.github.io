# A platform for managing your geospatial infrastructure

Published: **13 November 2026**

G3W-SUITE brings together QGIS project publishing and tools for managing web maps, collaborating with teams, and putting geospatial data to work.

{{#en}}By{{/en}}{{#it}}A cura di{{/it}} [Leonardo Lami](/en/about/leonardo-lami/)

## Start with the QGIS work you already have

Publish existing QGIS projects as WebGIS services while keeping their styles, symbols, editing forms and print layouts. You can bring your cartography to the web without rebuilding the project in a separate mapping tool.

Upload a `.qgs` or `.qgz` project, then use the administration panel to organize published projects. Set up users, roles and project permissions so each team can access the maps and tools it needs.

## Bring collaboration into the map

When online editing is enabled, teams can update geographic data through the web client and support field data collection, including mobile and offline workflows.

Configure forms, editing permissions and constraints around the way each project is managed. This keeps the map, the data and the people working with them connected in one workflow.

## Go beyond visualization

Interactive charts and temporal animations help users explore attributes and understand how geographic data changes over time.

For geospatial analysis, QGIS Processing models can run directly from the web client, with their results available in WebGIS projects. This brings analysis closer to the maps and workflows where the results are used.

## Share geographic information

Alongside WebGIS services, G3W-SUITE can expose metadata through a CSW (Catalog Service for the Web) service. This gives organizations another way to make geographic information discoverable and connect it with their wider geospatial infrastructure.

## Open source, built around QGIS

The platform integrates with QGIS and is available as open-source software under the MPL-2 licence. It can be deployed in the cloud or on premises, so organizations can choose an operating model that fits their infrastructure.
