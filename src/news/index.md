# News

Latest updates from G3W-SUITE

- **16 November 2026** — [A new website for G3W-SUITE](/en/news/new-website/)

  Discover the new website and how its pages, translations and documentation are prepared.

- **13 November 2026** — [A platform for managing your geospatial infrastructure](/en/news/geospatial-infrastructure/)

  G3W-SUITE brings together QGIS publishing, team collaboration, geospatial analysis and metadata sharing.

- **08 April 2026** — [Version 3.11](/en/news/v3.11/)

  Version 3.11 brings QGIS 3.44 LTR compatibility, major reductions in file count and compilation time, and new integrations with the QGIS API.

- **30 July 2025** — [Version 3.10](/en/news/v3.10/)

  Version 3.10 adds QGIS 3.40 LTR compatibility, Elasticsearch integration, Redlining Notes and improved DataPlotly chart management.

- **23 January 2025** — [Version 3.9](/en/news/v3.9/)

  Version 3.9 brings a redesigned map client, simpler editing-permission management and new editing features from QGIS.

- **17 June 2024** — [Version 3.8](/en/news/v3.8/)

  Version 3.8 adds QGIS 3.34 LTR support, customized themes, SVG and GeoPDF export, multigeometric editing and PDF layer downloads.

- **16 March 2024** — [MerginMaps Partnership](/en/news/merginmaps/)

  Gis3W is an official Mergin Maps partner, supporting field data collection workflows built on QGIS.

- **13 December 2023** — [Version 3.7](/en/news/v3.7/)

  Version 3.7 introduces a module for running QGIS ModelDesigner analyses on the web, alongside improvements to filtering, editing and map tools.

- **13 December 2023** — [Model Builder Processing](/en/news/model-builder-processing/)

  Run QGIS Processing models in the web client and use their results in WebGIS projects.

- **17 May 2023** — [Version 3.6](/en/news/v3.6/)

  Version 3.6 adds QGIS 3.28 LTR support, system logs, multilayer search, spatial bookmarks and project and group trash management.

- **15 November 2022** — [Version 3.5](/en/news/v3.5/)

  Version 3.5 adds stability improvements, symbology category controls, web editing tools and refactored time series.

- **05 April 2022** — [Version 3.4](/en/news/v3.4/)

  Version 3.4 adds embedded project management, cascading forms, custom WMS services, temporal layers and multiband raster plots.

- **07 October 2021** — [Version 3.3](/en/news/v3.3/)

  Version 3.3 introduces per-user editing permissions, QGIS expressions in online editing, Oracle Spatial editing and more API integration.

- **07 April 2021** — [Version 3.2](/en/news/v3.2/)

  Version 3.2 adds QGIS 3.16 LTR support, layer filtering, DataPlotly integration and QGIS AuthCFG support.

- **18 November 2020** — [Version 3.1](/en/news/v3.1/)

  Version 3.1 introduces DataPlotly charts, Atlas print layouts and broader QGIS API support.

- **30 June 2020** — [Version 3.0](/en/news/v3.0/)

  Version 3.0 brings a major code restructuring and the first QGIS API integration, expanding support for visualization, querying and editing.
