## <span id="cosa"></span>**Hosted or on-premise** Everything you need for your QGIS WebGIS

From project publishing to collaborative web editing, G3W-SUITE automatically inherits styles, forms and relations from your QGIS file.

- **Simple and fast**: Create your QGIS project; Use data on GeoDB or file system; Publish on WebGis
- **Users profiling**: Define users, groups and roles to differentiate management, access, online editing and functional modules
- **Customising**: Customize access portal and map client content; Create management environments and define their administrators; Activate the functional modules you need
- **Full of features**: **Integration with QGIS API**; Customizable searches; Simple and Atlas print layout; Time series animation; WPS module integration; CSW service for INSPIRE metadating
- **Editing on web**: Geometric and attribute editing also on 1:1 and 1:N relations; QGIS API based editing; Form and editing widgets inherited from QGIS project; Feature lock for multi-user editing; Geographical and alphanumeric constraints customizable for individual users
- **Desktop and mobile**: Responsive client for desktop and tablet; Web editing also in offline mode

## **Map client and administration** Features in detail

Two interfaces designed for end users and system managers.

### Map client

#### Optimised map client

**Graphic and functional optimization** for tablets and smartphones

**Customizable graphic interface** with texts, logos and contact references

**Geolocation functions** for field work

#### Basic tools

**Geographic search** tools and auto-zoom functions

**Base maps** (OSM, GoogleMaps, Yahoo, Bing)

**Print** based on **layout composer** (with **Atlas** support) linked to the **QGIS project**

**Metadata publication** defined on QGIS project

#### Advanced tools

**Query Builder** for custom searches

Data visualization based on **join and 1:N and N:M relations**

**Chart visualization** created with the QGIS plugin **DataPlotly**

Links to **web links and multimedia content**

**On-the-fly loading** of vector layers (.shp, .kml, .geojson, csv)

#### Online editing

Online editing, also **relational**, with **permission management**

**Form and widgets** for **simplified attribute compilation**

**Feature-lock** functions for **multi-user editing**

**Alphanumeric and geographic constraints** definable for single users or groups

Editing also **off line**

### Administration

#### Cartographic project publication

Ability to create **thematic cartographic containers** for **structured management** of WebGis services

Direct publication with **complete graphic correspondence with QGIS projects**

**Graphic search builder** activatable on individual services

**Cache management** and **base layer creation** from WebGis services

#### Data synchronization

Use data on your **PostGreSQL/PostGis, Oracle Spatial or MSSQL DB**

..but also **SQLite/SpatiaLite**, **GeoPackage, Shapefile, Virtual layer** and your **raster** data

#### Access and editing permissions management

**User creation** (individual and groups) and **access permissions management**

Management of **online editing permissions** on individual layers

**Alphanumeric constraints** based on **SQL and QGIS expressions** for creating **visualization and editing filters**

**Geographic constraints** for creating **visualization and editing filters**

#### Dedicated modules for PA

**Land registry** connection and tax checks

**CDU and associated regulations**

**Civic numbers and street directory** management

**RNDT and INSPIRE metadata**

## {{#it}}<span id="quick-start"></span>{{/it}}Quick Start

**Have you completed the installation of the suite on your server, or do you want to try publishing a project on the on-line demo?**

Find out how easy it is to do it in four simple steps!

### Create your QGIS project

Create your QGIS cartographic project defining all the aspects of interest: map content, symbology and labelling, legend structure, attribute query form, print layouts (free and atlas) and much more.

Remember to organize your projects and geographic data on your PC as illustrated and described in the [manual](/docs/datamanagement/#organization-of-data-and-projects).

{{#en}}![QGIS project](/img/site-qgis.jpg){{/en}}{{#it}}![Progetto QGIS](/img/site-qgis.jpg){{/it}}

### Upload your geographic data to the server

<iframe class="step__video" src="https://www.youtube.com/embed/8wKBoxxIs-4" title="G3W-SUITE Quick Start 2: upload your geo-data on the server" allow="accelerometer;autoplay;clipboard-write;encrypted-media;gyroscope;picture-in-picture" allowfullscreen loading="lazy"></iframe>

If your project is based on local files (Shp, GeoPackage, SpatiaLite, raster) it is necessary that such data is present on the server at the time of publication.

The [**FileManager**](/docs/datamanagement/#geographical-data-synchronization-on-the-server) module will allow you to upload such data reconstructing the same organization set up locally.

If your geographic data is on a PostGis or Oracle Spatial GeoDB, you simply need to allow access from the suite.

### Access G3W-SUITE and create the container for publishing

In order to publish a QGIS project you need to [create a Cartographic Group](/docs/admin-users/#add-group-users): these Groups are containers that allow you to thematically and functionally organize your WebGis services.

You can publish multiple WebGis services within each Cartographic Group, but remember that they must have the same projection system associated with the Group when created.

<iframe class="step__video" src="https://www.youtube.com/embed/P7hKruymHj4" title="G3W-SUITE Quick Start 3: creation of Cartographic Group" allow="accelerometer;autoplay;clipboard-write;encrypted-media;gyroscope;picture-in-picture" allowfullscreen loading="lazy"></iframe>

### Publish your QGIS project as a WebGis service

<iframe class="step__video" src="https://www.youtube.com/embed/gaxsTFC5uoo" title="G3W-SUITE Quick Start 4: publish your QGIS project as a WebGIS service" allow="accelerometer;autoplay;clipboard-write;encrypted-media;gyroscope;picture-in-picture" allowfullscreen loading="lazy"></iframe>

[Publish your QGIS project](/docs/g3wsuite_administration/#publication-of-new-webgis-services) by uploading the file (.qgs or .qgz) within the created Cartographic Group. **No plugin needed!**

All the settings and functions activated on the project will be automatically inherited by the WebGis service.

If you want to customize and activate additional functions on the online map, consult the [manual](/docs/g3wsuite_administration/#update-manage-webgis-services) and the [online tutorial](/docs/demo/).
