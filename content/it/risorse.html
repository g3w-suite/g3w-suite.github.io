Installazione

Guida Rapida d'Installazione

Installa G3W-Suite localmente tramite Docker e pubblica la tua prima mappa in 4 passi.

1. Prepara i dati e la mappa

Usa QGIS Desktop per configurare la tua mappa: imposta legende, etichette e stili. Ricorda di inserire i tuoi dati geografici all'interno di un database PostGIS o in un archivio GeoPackage.

1

2. Avvia G3W-Suite con Docker

Il modo più veloce per installare G3W-Suite è utilizzare Docker. Assicurati di avere Docker e Docker Compose installati, quindi esegui nel terminale:

# Clona l'infrastruttura Docker
git clone https://github.com/g3w-suite/g3w-suite-docker.git
cd g3w-suite-docker

# Avvia i container in background
docker-compose up -d
2

3. Installa il Plugin in QGIS

Apri QGIS Desktop, seleziona Plugin > Gestisci ed Installa Plugin e cerca "G3W-Suite Publisher". Installa il plugin per abilitare la pubblicazione guidata.

3

4. Connetti e Pubblica

Fai clic sull'icona del plugin in QGIS. Aggiungi un nuovo server inserendo l'URL della tua istanza (es. http://localhost:8080) e le tue credenziali amministrative. Seleziona il progetto QGIS attuale e fai clic su Pubblica. Il tuo WebGIS è pronto!

4
