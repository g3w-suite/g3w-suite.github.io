Explore Details

Features and Capabilities

Discover all the modules, technologies, and integrated tools in G3W-Suite, split between the web cartographic client and the administration panel.

Optimized Cartographic Client

Highly responsive interface for smartphones, tablets, and Desktop PCs. Includes integrated real-time GPS location features for field surveys and a customizable graphic layout with logos and texts of your organization.

Base Tools & Maps

Immediate integration with commercial and open-source base maps (OpenStreetMap, Google Maps, Bing Maps). Advanced searches with auto-zoom, layer transparency control, and structured legend view.

Advanced Tools & Charts

Integrated Query Builder for custom questions and searches. Native management of spatial relations, 1:N and N:M joins. Dynamic generation of interactive charts based on the QGIS DataPlotly plugin, historical time series, and multimedia attachments.

Online Relational Editing

Modify geometric shapes and attributes directly from the web, inheriting widgets and form designs configured in QGIS. Feature locking to prevent multi-user edit conflicts and offline editing for connectionless areas.

Cartographic client active
Premium Interface: Supports high-resolution printing by perfectly inheriting layout composer templates and print models defined in QGIS Desktop, including geographic Atlases.

Fast Project Publishing

Create and organize thematic geographic containers (groups) on the web. Instant publishing by uploading your .qgz project file. Full graphical correspondence of legends, theming styles, vector and raster layers.

Real-time Data Synchronization

Direct integration with enterprise relational and spatial databases: PostGreSQL/PostGIS, Oracle Spatial, MSSQL Server. Support for lightweight local formats such as SQLite/SpatiaLite, GeoPackage, Shapefile, and raster formats.

Granular User Profiling

Autonomous management of users and groups with differentiated roles. Configuration of edit permissions for individual layers and enabling of geographical filters and alphanumeric constraints (SQL / QGIS Expression) specific to each user.

Integrated PA Modules

Enable dedicated Public Administration modules: cadastral census integration, CDU (Certificate of Urban Destination) with dedicated print templates, modules for managing house numbers and road registries in compliance with RNDT and INSPIRE standards.

Administration
Administration Interface: Easily manage cache regeneration, file system synchronization, and user access monitoring.
Robust Architecture

Infrastructure & Open Standards

G3W-Suite is designed to guarantee stability, high performance, and full compatibility with international geographic standards.

QGIS Server

Fully leverages the QGIS Server API and engine to perfectly render your graphic styles and maps.

OGC Standards

Full compliance with international standards WMS, WFS, WCS and the CSW specification for geographic metadata.

Spatial Databases

Deep integration with the most popular relational and geographic databases with support for complex spatial queries.

API & Extensibility

Ability to extend the core functions by writing custom modules and integrating with third-party APIs.
